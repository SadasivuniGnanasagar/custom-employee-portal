# Custom Employee Portal with Zoho One Integration

A web-based employee portal with built-in authentication and Role-Based Access Control (RBAC), securely integrating with Zoho One APIs.

## Features

- Custom login and authentication system
- Role-Based Access Control (Admin, HR, Sales, Support, Finance)
- Zoho One API integration (People, CRM, Desk, Books)
- Admin dashboard for user and role management
- Audit logging for all activities
- Responsive modern UI

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
- **Authentication:** JWT
- **API Integration:** Zoho One OAuth 2.0

## Prerequisites

- Node.js (v16+)
- PostgreSQL (v14+)
- Zoho One trial account
- Zoho API Console credentials
